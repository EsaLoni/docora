## 1. Overview

UDIP Phase 11 integrates advanced foundation models, neural speech synthesis, and native document generation libraries. This guide outlines configuration variables, API keys, voice profiles, and operational parameters for all Phase 11 subsystems.

---

## 2. Google Gemini API Integration

The platform leverages Google Gemini (`gemini-2.5-flash`) for streaming chat, multi-source grounded reasoning, and structured JSON generation across all 9 Studio tools.

### Environment Configuration
```env
# Gemini API Key (Secret - Never expose to frontend or public commits)
GEMINI_API_KEY="AIzaSy..."

# Primary Model Identifier
GEMINI_MODEL="gemini-2.5-flash"

# Fallback / Backup Model
GEMINI_FALLBACK_MODEL="gemini-1.5-flash"

# Default Token Budget & Temperature
GEMINI_DEFAULT_TEMPERATURE=0.2
GEMINI_MAX_OUTPUT_TOKENS=4096
```

### Rate Limiting & Quota Management
- **Free Tier Constraints:** Google AI Studio free tier enforces **15 Requests Per Minute (RPM)** and 1,500 Requests Per Day (RPD).
- **Client Handling:** When 429 status is returned by the Gemini SDK, UDIP raises `LLMRateLimitError`, prompting the user interface to display a countdown timer rather than failing silently.
- **Recommended Production Setting:** Google Cloud Vertex AI or Pay-As-You-Go API key for enterprise concurrent workloads.

## 3. Microsoft Neural Speech Synthesis (`edge-tts`)

The Audio Overview engine generates two-host conversational podcasts without requiring expensive third-party speech API subscriptions by leveraging high-fidelity Microsoft neural voices.

### Supported Language Voice Profiles
| Language Code | Language | Alex Voice (Host A) | Sam Voice (Host B) |
| :---: | :--- | :--- | :--- |
| **`en`** | English (US) | `en-US-GuyNeural` | `en-US-JennyNeural` |
| **`es`** | Spanish (ES) | `es-ES-AlvaroNeural` | `es-ES-ElviraNeural` |
| **`fr`** | French (FR) | `fr-FR-HenriNeural` | `fr-FR-DeniseNeural` |
| **`de`** | German (DE) | `de-DE-ConradNeural` | `de-DE-KatjaNeural` |
| **`hi`** | Hindi (IN) | `hi-IN-MadhurNeural` | `hi-IN-SwaraNeural` |

### Synthesis Options
- **Format:** MP3 (128 kbps, 44.1 kHz stereo)
- **Audio Concatenation:** Individual dialogue turns are streamed asynchronously, aggregated in an in-memory buffer, and persisted via `StorageAdapter.save_artifact_file`.

## 4. Native Document Generation Libraries

### A. Presentation Engine (`python-pptx`)
- **Package:** `python-pptx >= 1.0.0`
- **Output Format:** Microsoft PowerPoint (`.pptx`)
- **Template Layouts:**
  - Layout 0: Title Slide (Deck Title, Subtitle, Date)
  - Layout 1: Content Slide (Slide Title, Subtitle, Bulleted Highlights)
- **Presenter Features:** Automatically embeds AI speaker notes into each slide's notes slide section.

### B. Report Generator (`python-docx`)
- **Package:** `python-docx >= 1.1.0`
- **Output Format:** Microsoft Word (`.docx`)
- **Styling Specs:**
  - Font Family: Calibri / Arial (Clean Corporate)
  - Primary Color: Deep Navy (`#1E3A8A`) for Title and Heading 1
  - Secondary Color: Slate Gray (`#475569`) for Heading 2
  - Margins: 1.0 inch (72pt) standard margins

### C. Data Table Engine (`openpyxl`)
- **Package:** `openpyxl >= 3.1.2`
- **Output Format:** Microsoft Excel (`.xlsx`)
- **Formatting Specs:**
  - Header Row: Dark Navy fill (`#1E3A8A`) with bold white text
  - Zebra Striping: Alternating light gray rows (`#F8FAFC`)
  - Auto-Fit: Dynamic column width calculation based on maximum cell content length
  - Borders: Thin gray cell gridlines (`#E2E8F0`)

## 5. Storage Adapters Configuration

Artifacts generated by Studio tools (PPTX, DOCX, XLSX, MP3) are stored securely according to the configured storage backend.

### Local Disk Storage (Default)
```env
STORAGE_BACKEND="local"
STORAGE_LOCAL_DIR="data/storage"
```
- Path structure: `data/storage/{workspace_id}/artifacts/{notebook_id}/{filename}`

### Supabase Storage (Cloud Mode)
```env
STORAGE_BACKEND="supabase"
SUPABASE_URL="https://your-project.supabase.co"
SUPABASE_KEY="your-service-role-key"
SUPABASE_STORAGE_BUCKET="udip-documents"
```
